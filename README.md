# VIT Shuttle

A modern, responsive web application that streamlines campus transportation at Vellore Institute of Technology (VIT). VIT Shuttle provides students with an intuitive interface to explore shuttle routes, helping them navigate the campus more efficiently.

**Live Demo:** https://vit-shuttle-react.vercel.app/

---

## Overview

Navigating a large university campus can be challenging, especially for new students. VIT Shuttle addresses this by providing a centralized platform for accessing shuttle route information in a clean, fast, and mobile-friendly interface.

The application is built with React and modern frontend technologies to deliver a seamless user experience across desktop and mobile devices.

---

## Features

- Clean and intuitive user interface
- Responsive design optimized for all screen sizes
- Browse available shuttle routes
- Quick access to pickup and drop locations
- Fast navigation and smooth user experience
- Optimized performance with modern frontend architecture

## Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js (v18 or later)
- npm or yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/vit-shuttle-react.git
```

Navigate to the project directory:

```bash
cd vit-shuttle-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
